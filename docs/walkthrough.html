Gemma harness walkthrough

A small local model loses track of a long task. This harness keeps the goal, the plan and the progress in a database, and gives the model one small step at a time. Step through the layers below. Each one shows a piece of a real run: task fix-bug, run 47, on gemma4:12b-mlx. The code is at github.com/Scooby-Dooby-Gu/gemma-harness.

Between runsLayer 10 writes notes once, at the end of a run. Layers 2, 5 and 8 of later runs read them. Nothing else carries over.

How it is measured

Six fixed coding tasks run in fresh folders. Code that is separate from the harness grades each result. The number to watch is false done: runs where the harness said done and the grader failed the work.
